Versi ini adalah frontend statis yang dapat dipasang di GitHub Pages.
Fitur: Dashboard, Data Siswa, CP, TP, ATP, Prota, Prosem, RPM Deep Learning per BAB, Penilaian per BAB + Akhir Semester, Rapor, Import/Backup JSON.

Referensi BAB SIBI dimasukkan hanya untuk kombinasi buku yang telah diverifikasi. Kombinasi lain tidak dibuat-buat.

Cara GitHub Pages: upload index.html ke root branch main, lalu Settings > Pages > Deploy from a branch > main > /(root).
